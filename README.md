# Transkribator

Транскрибация аудиозаписей в текст. Берёт аудиофайл (aac, mp3, wav, m4a,
flac, ogg, opus, wma, mp4-звук), распознаёт речь и сохраняет результат с
таймкодами в `.md` файл рядом с записью.

Работает на модели Whisper через `faster-whisper`. Аудио декодируется
библиотекой PyAV (пакет `av`) — у неё ffmpeg встроен внутрь, ставить
системный ffmpeg отдельно не нужно.

Проект живёт на сервере — локальной копии на ноутбуке нет и не планируется
(см. `CHANGELOG.md`, запись от 2026-08-27).

## Где что лежит

- `transcribe.py` — единственный скрипт, вся логика в нём.
- `records/` — аудиозаписи и готовые транскрипты. **В git не попадает** —
  там могут быть чувствительные записи совещаний.
- `CHANGELOG.md` — журнал разработки: что менялось и почему.

## Сервер

Linux Mint, `<SERVER_USER>@<SERVER_HOST>:<SERVER_PORT>`, проект в `~/transkribator/`,
своё окружение `.venv` (без conda — создано штатным `python3 -m venv`,
т.к. на сервере нет conda и нет прав root на `apt install`).

```bash
ssh -p <SERVER_PORT> <SERVER_USER>@<SERVER_HOST>
cd ~/transkribator
.venv/bin/python transcribe.py records/запись.aac
```

Полезные флаги:
- `--model tiny|base|small|medium|large-v3` — размер модели (по умолчанию `medium`).
  Чем больше — тем точнее и медленнее.
- `--language ru` — язык записи (по умолчанию автоопределение).
- `--output путь.md` — куда сохранить результат (по умолчанию рядом с аудио).

## Рабочий сценарий

Не заходить на сервер руками — прислать запись в чат Claude Code и
попросить транскрибировать: файл сам зальётся на сервер по `scp`,
распознается там и результат вернётся.
