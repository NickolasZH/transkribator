# Журнал разработки

## 2026-08-27 — старт проекта, локальный запуск, перенос на сервер

**Сделано:**
- Создано conda-окружение `asr` (Python 3.11) на рабочем ноутбуке,
  установлены `ffmpeg` (conda-forge) и `faster-whisper`.
- Написан `transcribe.py`: принимает путь к аудио, распознаёт речь через
  Whisper (`faster-whisper`), сохраняет результат с таймкодами в `.md`
  рядом с аудио. Форматы — всё, что понимает PyAV (aac, mp3, wav, m4a,
  flac, ogg, opus, wma, mp4).
- Проверено на синтетическом тестовом `.aac` и на реальной записи
  совещания (~33 минуты) — распознавание корректное, кириллица без
  проблем.
- Тот же проект развёрнут на Linux-сервере (`<SERVER_USER>@<SERVER_HOST>:<SERVER_PORT>`,
  Ubuntu 5.15, Python 3.10) — venv вместо conda, окружение `~/transkribator/.venv`.
- Реальная запись (та же, ~33 мин, модель `medium`) протестирована на
  обеих машинах: сервер — 32 мин, ноутбук — почти час. Дальше рабочий
  сценарий — распознавание на сервере, а не локально.

**Грабли и как обошли:**
- *Conda-ffmpeg на Windows не запускался* (`STATUS_DLL_NOT_FOUND`) —
  не хватало рантайма MinGW. В итоге не понадобилось чинить: у
  `faster-whisper` есть своя зависимость `av` (PyAV) со встроенным ffmpeg,
  системный конда-ffmpeg для транскрибации не нужен.
- *pip/huggingface_hub падали с `Missing dependencies for SOCKS support`* —
  в реестре Windows включён локальный SOCKS-прокси
  (`HKCU\...\Internet Settings`, `socks=127.0.0.1:10808`), а библиотеки не
  умеют работать с SOCKS без `pysocks`. Решение — отключать прокси
  (`HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`/`NO_PROXY`) на время работы
  скрипта; зашито в начало `transcribe.py`, срабатывает только на Windows
  (`os.name == "nt"`), сервер не трогает.
- *На сервере нет `python3-venv` и нет прав `sudo` без пароля* — venv
  создан флагом `--without-pip` (не требует `ensurepip`/системного пакета),
  pip затем поставлен вручную через `get-pip.py`. Пароли sudo не вводили и
  не будем — если понадобится системный пакет, разово попросить
  пользователя выполнить `sudo apt install ...` самостоятельно.

**Открытые вопросы:**
- Модель `medium` иногда путает акронимы (например, «ОТиПБ» → «от APB» в
  одном из прогонов). Если качество важнее скорости — пробовать
  `large-v3`, но заметно медленнее на CPU.
- Скрипт пока гоняется вручную (вставить путь, запустить). Если станет
  неудобно — можно обернуть цикл «прислали файл в чат → залили на сервер →
  распознали → забрали результат» в один вспомогательный скрипт.
