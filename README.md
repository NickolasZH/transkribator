# Transkribator

Локальная транскрибация аудиозаписей в текст. Берёт аудиофайл (aac, mp3,
wav, m4a, flac, ogg, opus, wma, mp4-звук), распознаёт речь и сохраняет
результат с таймкодами в `.md` файл рядом с записью.

Работает на модели Whisper через `faster-whisper`. Аудио декодируется
библиотекой PyAV (пакет `av`) — у неё ffmpeg встроен внутрь, ставить
системный ffmpeg отдельно не нужно.

## Где что лежит

- `transcribe.py` — единственный скрипт, вся логика в нём.
- `records/` — аудиозаписи и готовые транскрипты. **В git не попадает** —
  там могут быть чувствительные записи совещаний.
- `CHANGELOG.md` — журнал разработки: что менялось и почему.

## Запуск

### Локально (Windows, conda-окружение `asr`)

```powershell
conda activate asr
python transcribe.py records\запись.aac
```

Полезные флаги:
- `--model tiny|base|small|medium|large-v3` — размер модели (по умолчанию `medium`).
  Чем больше — тем точнее и медленнее.
- `--language ru` — язык записи (по умолчанию автоопределение).
- `--output путь.md` — куда сохранить результат (по умолчанию рядом с аудио).

### На сервере (Linux Mint, `<SERVER_USER>@<SERVER_HOST>:<SERVER_PORT>`)

Тот же скрипт лежит в `~/transkribator/` на сервере, там своё окружение
`.venv` (без conda — создано штатным `python3 -m venv`, т.к. на сервере нет
conda и нет прав root на `apt install`). Сервер заметно быстрее ноутбука
(на записи ~33 мин: сервер — 32 мин, ноутбук — почти час, модель `medium`).

```bash
ssh -p <SERVER_PORT> <SERVER_USER>@<SERVER_HOST>
cd ~/transkribator
.venv/bin/python transcribe.py records/запись.aac
```

Обычный рабочий сценарий — не заходить на сервер руками, а прислать запись
в чат Claude Code и попросить транскрибировать: файл сам зальётся на
сервер, распознается там и результат вернётся.
