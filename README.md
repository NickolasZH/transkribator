**[Read this in English](README.en.md)**

Простая программа: даёте ей аудиозапись (например, запись встречи или
лекции) — она слушает её и отдаёт текст с таймкодами. Работает целиком
на вашем компьютере: сама запись никуда не отправляется, из интернета
скачивается только один раз модель распознавания речи (при первом
запуске).

Пример результата (`records/встреча.md`):

```
# Транскрипт: встреча.aac

**[00:00 – 00:07]** Добрый день, начинаем совещание.

**[00:07 – 00:15]** Первый вопрос повестки — бюджет на следующий квартал.
```

## Что нужно, чтобы попробовать

- Компьютер (Windows, macOS или Linux) — специальная видеокарта не
  обязательна, программа умеет работать и на обычном процессоре, просто
  медленнее.
- Python версии 3.10 или новее.
- Аудиофайл, который нужно превратить в текст: `aac`, `mp3`, `wav`,
  `m4a`, `flac`, `ogg`, `opus`, `wma` или звук из `mp4`.
- Свободное место на диске: 1–3 ГБ под модель распознавания речи (в
  зависимости от того, какую модель выберете — см. таблицу ниже).

Программисту писать не нужно — весь код уже готов, нужно только
установить и запустить.

## Быстрый старт

### 1. Установите Python

Если Python ещё не установлен — скачайте с
[python.org](https://www.python.org/downloads/) (версия 3.10 или новее)
и поставьте, отметив галочку «Add Python to PATH» при установке на
Windows.

Проверить, что Python установлен, можно командой:

```bash
python --version
```

### 2. Скачайте проект

Если у вас установлен git:

```bash
git clone https://github.com/NickolasZH/transkribator.git
cd transkribator
```

Если git не установлен — на странице репозитория на GitHub нажмите
зелёную кнопку **Code → Download ZIP**, распакуйте архив и откройте
терминал в этой папке.

### 3. Создайте виртуальное окружение и установите зависимости

Виртуальное окружение — это отдельная «песочница» для библиотек этого
проекта, чтобы они не конфликтовали с другими программами на
компьютере.

```bash
python -m venv .venv
```

Активируйте его:

```bash
# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### 4. Запустите транскрибацию

Положите свой аудиофайл, например, в папку `records/`, и запустите:

```bash
python transcribe.py records/встреча.aac
```

При первом запуске программа скачает из интернета модель распознавания
речи (может занять несколько минут — зависит от скорости интернета),
дальше все запуски будут быстрее, потому что модель уже на диске.

Когда программа закончит, рядом с аудиофайлом появится файл с тем же
именем и расширением `.md` — это и есть готовый транскрипт с
таймкодами.

## Какую модель выбрать

Флаг `--model` задаёт размер модели распознавания речи. Чем модель
больше — тем точнее распознаёт речь, но тем медленнее работает и
больше весит:

| Модель      | Точность          | Скорость          | Размер на диске |
|-------------|--------------------|--------------------|------------------|
| `tiny`      | низкая              | очень быстрая       | ~75 МБ           |
| `base`      | ниже средней        | быстрая             | ~150 МБ          |
| `small`     | средняя             | средняя             | ~500 МБ          |
| `medium`    | хорошая (по умолчанию) | медленнее       | ~1.5 ГБ          |
| `large-v3`  | самая высокая       | самая медленная      | ~3 ГБ            |

Если не уверены — оставьте значение по умолчанию (`medium`), это
разумный баланс между качеством и скоростью. Для быстрой черновой
расшифровки подойдёт `small` или `base`.

## Все параметры запуска

```bash
python transcribe.py путь/к/файлу.mp3 [параметры]
```

| Параметр       | Что делает                                              | По умолчанию      |
|----------------|----------------------------------------------------------|--------------------|
| `--model`      | размер модели: `tiny`/`base`/`small`/`medium`/`large-v3`  | `medium`           |
| `--language`   | код языка записи, например `ru` или `en`                 | определяется сама  |
| `--device`     | где считать: `cpu` (обычный процессор) или `cuda` (видеокарта NVIDIA) | `cpu` |
| `--output`     | куда сохранить результат (свой путь к `.md` файлу)        | рядом с аудио      |

Пример: быстро расшифровать русскую запись на видеокарте маленькой
моделью и сохранить в отдельное место:

```bash
python transcribe.py records/встреча.aac --model small --language ru --device cuda --output итог.md
```

## Частые вопросы

**Первый запуск долго идёт — это нормально?**
Да, при первом запуске скачивается модель распознавания речи из
интернета. Все следующие запуски с той же моделью будут намного
быстрее — она уже сохранена на диске.

**Нет интернета — программа вообще не заработает?**
Интернет нужен только один раз — чтобы скачать модель. После этого
можно работать офлайн.

**Есть ли видеокарта — как её использовать?**
Если у вас видеокарта NVIDIA с поддержкой CUDA, добавьте флаг
`--device cuda` — распознавание пойдёт заметно быстрее. Без видеокарты
NVIDIA используйте `--device cpu` (это и так значение по умолчанию).

**Куда уходят мои аудиозаписи?**
Никуда. Вся обработка происходит локально на вашем компьютере.
Единственное обращение к интернету — скачивание модели с сайта Hugging
Face при первом запуске.

**Программа не видит формат моего файла**
Список проверенных форматов — в разделе выше. Другие форматы тоже
могут сработать (программа предупредит и всё равно попробует), но
гарантии нет. Проще всего заранее перекодировать файл в `mp3` или
`wav`.

**Ошибка при установке / что-то не ставится**
Убедитесь, что используете Python 3.10 или новее (`python --version`)
и что виртуальное окружение активировано (в начале строки терминала
должно быть `(.venv)`). Если ошибка про недостающие системные
библиотеки — попробуйте обновить `pip`: `python -m pip install --upgrade pip`.

## Технологии внутри

- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) —
  быстрая реализация модели распознавания речи Whisper (OpenAI).
- [PyAV](https://github.com/PyAV-Org/PyAV) — декодирование аудио любых
  форматов, ffmpeg уже встроен внутрь, отдельно ставить не нужно.
